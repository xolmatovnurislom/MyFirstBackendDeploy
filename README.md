# MyFirstBackendDeploy

A backend application built with Node.js,
Express.js, and MongoDB.

## Technologies
- Node.js
- nodemon
- Express.js
- MongoDB
- Mongoose
- nodemailer
- JWT
- bcrypt
- zod

## Installation

1. Clone the repository
2. Install dependencies

npm install

3. Create a .env file
4. Start the server

npx nodemon app
or 
npm run dev
